Impostazioni GitHub

Per salvare modifiche (aggiungere/rimuovere titoli, cambiare soglie) questa pagina scrive direttamente nel tuo repository GitHub tramite le API di GitHub, usando un token che resta salvato solo in questo browser — non viene mai inviato altrove. Crea un token su github.com/settings/personal-access-tokens/new (fine-grained, limitato a questo repository, permessi "Contents: Read and write" e, se vuoi usare il pulsante ⟳ per aggiornare i prezzi al volo, anche "Actions: Read and write").

Watchlist

I prezzi e il P/E vengono aggiornati una volta al giorno (giorni feriali, a mercati chiusi) da una GitHub Action che scrive prices.json in questo stesso repository — oppure quando premi ⟳ per lanciarla subito. Quando un prezzo non è disponibile con una chiusura di borsa recente e certa, il titolo resta "In attesa dati" invece di mostrare un numero vecchio. Le notizie vengono aggiunte manualmente (anche chiedendo a Claude di cercarle e incollandole qui).
